# Sniem

## Introduction

A modular editing method package for Emacs.

## Documents

2. `README.md`: README file written in English.
3. `README.zh.md`: README file written in Chinese.

## Principles

**These are the rules you must follow**:

1. Using English to write the comments in code.
2. Only add new function when it's necessary, in order to make the code more readable.
3. You can get the git repository info, but **never** execute commands that can change git status without my order.
4. Keep comments concise and explain why the code does something rather than what it does, so they serve as a record of pitfalls and lessons learned.
